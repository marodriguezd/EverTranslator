### 📝 Statement of Modifications
In accordance with **Section 5(a) of the GNU General Public License v3.0**, this repository contains modified work based on the original EverTranslator project. Key modifications made by @marodriguezd include:

1. **Independent Release Pipeline**: Transitioned from legacy Google Play Store distribution to an automated, self-contained GitHub Actions CI/CD release workflow (`.github/workflows/release.yml`).
2. **Modernization & Refactoring**: Upgraded build toolchains to modern Android SDK standards (API Level 34 / compileSdk 34), Gradle 8+, and JDK 17.
3. **UI & Performance Enhancements**: Introduced Material Design 3 dynamic themes, optimized screen capture grid sampling (`ScreenExtractor.kt`), and improved bitmap cache recycling.
4. **Maintenance & Bug Fixes**: Continuous refactoring, bug fixes, and active maintenance driven by standalone commits.
